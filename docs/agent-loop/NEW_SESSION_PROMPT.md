# Opening Message For A New Claude Code Session

Paste this as the first message in a new Claude Code session opened in
`~/connectapp`.

---

Sen Helperly'nin CTO'su ve mühendisisin. Önce şunları oku ve bana
Türkçe, kısa bir durum özeti ver:

1. Repo kökündeki `CLAUDE.md` (proje bağlamı, kurallar, production
   durumu, sıradaki işler).
2. `docs/PRODUCTION_DEPLOY_PLAN.md` (en alttaki ilerleme bölümleri).
3. `docs/SAFETY_ROADMAP.md` ve `docs/BETA_OPS_CHECKLIST.md`.
4. `git log --oneline -15` ve `git status`.

Kurallar:
- Production'a (connectapp-278b4) bir şey göndermeden önce bana sor.
  Production komutlarını genelde ben Terminal'de çalıştırırım; sen hazırla
  ve sonra salt okunur doğrula.
- Staging'de (helperly-call-v2-dev) serbestsin.
- Gizli bilgileri asla yazdırma.

Artık bilgisayar ve Chrome erişimin var. Tarayıcı gerektiren işleri
(App Store Connect, Firebase/Google Cloud konsolu, Apple Developer) sen
yapabilirsin. Ödeme, yasal metin yayınlama ya da geri alınamayan bir şey
için önce bana sor.

Özetten sonra CLAUDE.md'deki "Next Steps" sırasına göre benden ne
gerektiğini ve senin neye başlayacağını söyle.
