# French Glossary (Québec)

Helperly is people helping each other through lived experience. It is
**not** a care or professional service. In Québec, "aidant" / "proche
aidant" means a family caregiver, so we do not use it.

| Concept | English | French | Where |
|---|---|---|---|
| Looking for help (action) | Find a helper | **Trouver de l'aide** | Home button, Find a helper title |
| Person who helps (noun) | helper | **personne-ressource** (pl. personnes-ressources) | Search badge, lists, booking payout |
| Offering help (role) | I'm here to give help / Give Help | **Je veux partager mon expérience** / **Partager mon expérience** | Onboarding role, Edit profile |
| Seeking help (role) | I'm here to get help | **Je cherche de l'aide** | Onboarding role |
| Community | Helpers share personal experience | **Les membres** partagent leur expérience | Advice notice |
| Session | session | **séance** | Consultations, ratings |
| Chat | chat | **clavardage** (UI), conversation | Modes, chat title |
| Email | email | **courriel** | Auth screens |

Rules:
- Gender-neutral wording ("personne-ressource", "membre"), never
  "aidant/aidante".
- Québec usage: courriel, clavardage, téléverser, magasiner-style
  terms are fine; space before ":" and "%" (French typography); no space
  before "?" in Québec style.
- Stored ids (topics, post types, countries) never change; only labels are
  translated (see `lib/l10n/value_labels.dart`).

A native French reviewer should confirm these before public launch.
